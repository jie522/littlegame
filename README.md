每人用**自己的手機**,2~4 人連線一起玩的可愛小遊戲合集!

## 🎮 立即遊玩

用手機瀏覽器打開(不需安裝):

**https://jie522.github.io/littlegame/**

> 🤖 **想自己一個人玩?** 在首頁按「單人玩(對電腦)」,不用網路、不用房號,九款遊戲都可以對電腦;電腦強度分簡單 / 普通 / 困難。多人房間裡房主也可以按「加入電腦」補人數。

1. 一個人按「🏠 建立房間」,會得到 4 位數房號
2. 其他人輸入房號按「加入」(或點房主分享的邀請連結)
3. 在房間裡點自己的頭像,可以從 **8 個角色**(兔兔、熊熊、柴柴、貓貓、睏睏貓、小貓熊、企鵝、水獺)選一個,同一個角色只能一個人用
4. 人到齊後,房主選遊戲、按開始
5. 每個人看自己的手機螢幕玩!

> 💡 建議大家連**同一個 Wi-Fi**,連線最穩定。玩的時候請保持網頁開著,不要切到別的 App。

## 🎲 九款小遊戲

| 遊戲 | 類型 | 玩法 |
|---|---|---|
| ⚡ 閃電快手 | 反應 | 看到 ⭐ 最快拍的得分(比每台手機自己量的反應毫秒數,網路慢也公平);太早拍出局,💣 出現時拍到扣分 |
| 🧮 算數小天才 | 益智 | 同時出題搶答,最快答對的得分,越後面越難 |
| 🎨 顏色對對碰 | 益智+反應 | 「字的意思」和「字的顏色」一樣才能拍,拍錯扣分 |
| 🃏 萌寵翻翻樂 | 益智 | 大家看同一副牌輪流翻,配對成功可以再翻一次 |
| ♟️ 暗棋大對決 | 益智 | 2 人翻棋對戰(超過 2 人時抽籤上場、其他人觀戰);大吃小、兵吃帥、炮隔子吃,吃光對方就贏 |
| 🪖 坦克大戰 | 反應+合作 | 大家同一隊守護基地 🦅!方向鍵移動、按鈕發射,打倒敵人坦克得分(👾 1 分、👻 2 分、🤖 3 分),每人 3 條命 |
| 🪜 小朋友下樓梯 | 反應 | 大家在同一個豎井往下跳!平台會一直往上升,有回血、尖刺、輸送帶、彈簧、會碎的平台,下到最深的人獲勝 |
| ⭕ 九子棋 | 益智 | 2 人對戰(棋子顏色可以自己選,8 種顏色):每人 9 顆棋:先輪流放子、再沿線走子,成三就吃對方一顆;只剩 3 顆時可以飛,對方剩 2 顆或被困住就贏 |
| 🥞 疊疊三連線 | 益智+對戰 | 2~4 人、4x4 棋盤,每人 5 顆棋:放 1~3 顆(可疊在別人上面,最多 3 層)或移動最上面的棋;從上往下看,最上面的顏色連成 3 格就贏 |

每場遊戲的贏家可獲得一顆 ⭐。

## 🛠 技術

- 純 HTML / CSS / JavaScript,放在 GitHub Pages 上,不需要自己的伺服器
- 手機之間用 [PeerJS](https://peerjs.com/)(WebRTC 點對點)連線,房主的手機負責主持遊戲
- 配對時會用到 PeerJS 的免費公用伺服器;少數行動網路(4G/5G)可能因 NAT 限制連不上,改連同一個 Wi-Fi 即可

本機執行:

```bash
python -m http.server 8000
```

然後打開 http://localhost:8000
