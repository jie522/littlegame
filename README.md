每人用**自己的手機**,2~4 人連線一起玩的可愛小遊戲合集!

## 🎮 立即遊玩

用手機瀏覽器打開(不需安裝):

**https://jie522.github.io/littlegame/**

> 🤖 **想自己一個人玩?** 在首頁按「單人玩(對電腦)」,不用網路、不用房號,十八款遊戲都可以對電腦;電腦強度分簡單 / 普通 / 困難。多人房間裡房主也可以按「加入電腦」補人數。

1. 一個人按「🏠 建立房間」,會得到 4 位數房號
2. 其他人輸入房號按「加入」(或點房主分享的邀請連結)
3. 在房間裡點自己的頭像,可以從 **8 個角色**(兔兔、熊熊、柴柴、貓貓、睏睏貓、小貓熊、企鵝、水獺)選一個,同一個角色只能一個人用
4. 人到齊後,房主選遊戲、按開始
5. 每個人看自己的手機螢幕玩!

> 💡 建議大家連**同一個 Wi-Fi**,連線最穩定。玩的時候請保持網頁開著,不要切到別的 App。

## 🏁 闖關模式(單人)

首頁按「闖關模式」,可以選「🚌 公車大塞車」或「🅿️ 停車大師」(3D 開車停進格子,100 關(25 關是卡車連結車,車頭拖著貨櫃、倒車會折刀),有停電、方向盤裝反、香蕉皮、減速丘,沒有會動的東西,難度靠格子越來越窄)。

### 🚌 公車大塞車

玩法參考 Bus Traffic Fever:停車場裡的公車各種角度亂停(一排排、斜的、一圈圈、螺旋、亂堆),車頂箭頭是它會開的方向。點公車,它會往箭頭方向直直開,被別的車擋住就彈回來;開出去後會繞到上面停進候車格。上方 U 字形的人龍會坐上**同顏色**的公車,坐滿就開走。候車格全部停滿、排頭的乘客又沒有車可以上就輸了;所有乘客都上車就過關。道具:🔄 轉向(每關 2 次,讓一台公車調頭)、🅿️ 加格(每關 1 次,也可以直接點候車格最右邊的「+」)。關卡會一關比一關難:公車越來越多、顏色越來越多、要先移開別台車的連鎖越來越長,第 16 關起還會出現「?」神秘車(前面被擋住時看不到顏色,路一通就會顯示);難度分成 簡單/普通/困難/超難/地獄。每一關都保證有解,進度會自動存在手機裡。選關畫面點「🔑 輸入密碼」輸入 0522 可以解鎖跳關,之後能直接輸入想去的關卡;玩的時候點上方的「第 N 關」可以隨時回到選關畫面。

## 🏅 戰績與排名

首頁左上角點「戰績」可以看到:段位(新手 → 銅牌 → 銀牌 → 金牌 → 白金 → 鑽石 → 傳說,依累計勝場升級)、總場次、勝場、勝率、最高連勝、各款遊戲依勝率的排名,以及最近 10 場紀錄。每場結算畫面也會顯示該遊戲的勝率。戰績只存在自己的手機瀏覽器裡。

## 🛠 技術

- 純 HTML / CSS / JavaScript,放在 GitHub Pages 上,不需要自己的伺服器
- 手機之間用 [PeerJS](https://peerjs.com/)(WebRTC 點對點)連線,房主的手機負責主持遊戲
- 配對時會用到 PeerJS 的免費公用伺服器;少數行動網路(4G/5G)可能因 NAT 限制連不上,改連同一個 Wi-Fi 即可

本機執行:

```bash
python -m http.server 8000
```

然後打開 http://localhost:8000
