# 🐰🐻🐸🐱 萌萌派對 Party

一支手機,2~4 人圍著一起玩的可愛小遊戲合集!把手機平放在桌上,每個人負責自己的顏色區域,上方玩家的畫面會自動倒轉。

## 🎮 立即遊玩

開啟 GitHub Pages 網址即可(手機瀏覽器直接玩,不需安裝):

**https://jie522.github.io/littlegame/**

## 🎲 五款小遊戲

| 遊戲 | 類型 | 玩法 |
|---|---|---|
| ⚡ 閃電快手 | 反應 | 看到 ⭐ 最快拍的得分,太早拍出局,💣 出現時拍到扣分 |
| 🥕 狂點拔蘿蔔 | 反應 | 8 秒內狂點自己的區域,點最多次的人把蘿蔔拔出來! |
| 🧮 算數小天才 | 益智 | 搶答算數題,答錯該題就不能再答,越後面越難 |
| 🎨 顏色對對碰 | 益智+反應 | 「字的意思」和「字的顏色」一樣才能拍,拍錯扣分 |
| 🃏 萌寵翻翻樂 | 益智 | 輪流翻牌配對,配對成功可以再翻一次 |

每場遊戲的贏家可獲得一顆 ⭐,星星數會保存在手機上。

## 🛠 技術

純 HTML / CSS / JavaScript,沒有任何外部套件,支援多點觸控、音效與震動回饋。

本機執行:

```bash
python -m http.server 8000
```

然後打開 http://localhost:8000
